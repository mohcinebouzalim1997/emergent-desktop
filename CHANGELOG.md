# Changelog

## v0.3.0 — Initial native command deck

- .NET 10 WPF four-window transparent interface.
- Local Windows CPU, RAM and network telemetry.
- Animated status light, live clock and rolling CPU graph.
- Editable, categorized launcher shortcuts.
- Per-widget remembered positions and notification tray controls.
- Separate sci-fi Earth wallpaper.
- No external packages, telemetry upload, or startup persistence.

Known limitation: widget windows are not attached to the Explorer desktop layer. See README.
